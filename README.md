# beckchristensen.dev

Personal portfolio website for Charles Beck Christensen — software engineering graduate, audio engineer, and radio host. Built with vanilla HTML and CSS. No JavaScript, no frameworks, no build step.

## Stack

- HTML5 (semantic markup)
- CSS3 (custom properties, grid, flexbox, clamp-based fluid type)
- Popover API (mobile dropdown menu)
- Space Mono via Google Fonts
- Netlify (deployment)

## Structure

```
/
  index.html        — all content and markup
  styles.css        — all styles
  pics/             — project screenshots and personal photos
  docs/             — resume PDF, and the resume.html it is printed from
  netlify.toml      — Netlify deployment config
```
